# ContextGate 0.8.1

**优化首次加载，限制审计维护操作的等待时间。**

[English](0.8.1.md) · [安装](../install.zh-CN.md) · [运维](../operations.zh-CN.md)

## 修复内容

- 管理页面、数据源编辑和设置面板按需加载。生产构建入口 JavaScript 从 770.40 kB 减至 426.66 kB（未压缩）；这是包体积测量，不代表浏览器延迟保证。直接进入页面也能加载完整共享样式。
- 保留访问过的设置表单，切换分区时保护未保存修改、正在执行的操作和一次性凭证。审计状态轮询在面板或浏览器页面隐藏时暂停；服务端上报继续运行。
- 内嵌 HTML 重新验证缓存，带内容哈希的资源长期缓存，缺失资源返回不缓存的 404。延迟加载失败时提供显式刷新入口，并遵守未保存修改保护。
- 审计写入使用独立的十秒预算，覆盖连接池和锁等待；保留同步持久化、失败语义以及导出游标所需的提交顺序保证。
- 过期审计记录每批最多删除 1,000 条，每小时清理任务总预算一分钟。30 天保留边界不变；未完成的清理会记录日志并在下次重试。
- 拆分登录、设置、连接器目录和 OAuth 授权同意组件，展示标签不再依赖页面模块。

## 兼容与升级

从 **0.6.x、0.7.x 或 0.8.0** 升级：备份 PostgreSQL 元数据库、匹配主密钥和部署配置，停止服务，更换完整的 0.8.1 程序包或镜像；使用原数据库 URL、密钥和来源文件目录启动，再检查已有查询与审计。不新增元数据迁移，也不强制轮换凭证。

审计持久化超过预算时返回审计失败；成功查询仍须等待其审计记录提交。已有 `elapsed_ms` 不包含最终审计写入，端到端延迟应使用客户端计时。本版不宣称提高持续审计吞吐量。

更早版本请参照[安装升级指南](../install.zh-CN.md)。已有路由、查询与配置 MCP 工具、发布契约保持兼容。

## 发行包与验证

下载 `contextgate-0.8.1-linux-arm64.tar.gz` 或 `contextgate-0.8.1-linux-amd64.tar.gz`，并使用 `SHA256SUMS` 校验。保留启动器、`libexec` 和私有 C++ 库的完整目录。要求 Linux glibc 2.36+ 及 PostgreSQL 元数据库，运行时无需 Node.js。继续提供 `mcpdbhub` 启动器。

[发行附件](https://github.com/SamuelSupe/contextGate/releases/tag/v0.8.1)包含 `release-verification.json`、`dist-arm64.json`、`dist-amd64.json`、`download-arm64.json` 和 `download-amd64.json`。具体源提交、原生双架构 CI、包摘要及实际程序包和下载回验结果以这些记录为准。本机 amd64 程序包通过 arm64 宿主机上的 OrbStack 仿真执行。

包检查覆盖 PostgreSQL 与 HTTP API 查询、HTTP/stdio MCP、模板与本体上下文、管理员恢复、重启持久化、撤销及 OTLP HTTP/protobuf、gRPC。完整外部数据库矩阵保留历史证据；本维护版不宣称重新执行完整矩阵、长期压力测试或真实云数仓验证。详见[验证记录](../validation.zh-CN.md)。
