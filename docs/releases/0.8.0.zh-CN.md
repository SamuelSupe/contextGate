# ContextGate 0.8.0

**将已有业务查询发布为可复用的 Agent 工具。**

[English](0.8.0.md) · [查询发布指南](../query-publishing.zh-CN.md) · [客服示例](../../examples/query-publishing/README.zh-CN.md) · [安装](../install.zh-CN.md)

## 新增与优化

- **连续查询发布流程：** 选择来源、提供原生查询或固定 HTTP 读取操作、补充参数和结果含义、真实试跑、审阅整个数据源草稿后发布。支持保存进度、恢复及冲突合并，保留无关条目。
- **本体与查询关联：** 按名称关联已映射概念，从实体创建查询，并在同一编辑器查看定义。分别展示已关联和当前可执行的查询数量；Agent 通过现有语义工具发现授权范围内的概念与查询关系。
- **统一查询目录：** 区分可用查询、管理员草稿、待处理查询和全部定义。点击名称直接进入工作区，返回恢复筛选、分页快照、位置和焦点。选择 Agent 后隐藏管理视图，后端同样拒绝通过 Agent 视角读取草稿。
- **明确客户端接入：** 依次接入 Agent、复制工具调用、确认调用。自动等待最长 2 分钟；离开或隐藏页面、收起面板、查询或授权变更时取消。只统计匹配来源、模板、执行版本和所选 Agent 的成功调用，预览不计入。
- **更简洁的日常界面：** 首页按管理员保留最多五个最近查询，突出一个下一步操作；优化帮助提示、设置分组、列表、空状态、参数示例、窄屏操作及本体详情侧栏。

发布、执行验证、连接检测、健康检查和业务验收分别展示。查询成功不等于业务答案正确；[试点工作表](../query-pilot.zh-CN.md)用于记录真实配置投入、答案质量和持续复用，本版不将测试结果作为客户收益证明。

## 兼容与升级

从 **0.6.x 或 0.7.x** 升级：备份 PostgreSQL 元数据库、匹配主密钥和部署配置，停止服务，更换完整 0.8.0 程序包或镜像；使用原数据库 URL、密钥和来源文件目录启动，再检查已有查询与审计。

本版**不新增元数据迁移，不强制轮换凭证**。管理员账号、个人配置 MCP 身份、查询 Agent/OAuth 授权、语义发布、本体映射和旧 URL 保持兼容。语义导出仍为 v2，继续支持导入 v1。查询 MCP 仍为 15 个工具，配置 MCP 为 22 个；每个查询模板通过 `execute_query_template` 执行，不单独注册新 MCP 工具。

再次打开查询时，原浏览器续办记录转换为有界最近列表。缓存仅保存来源、模板和 Agent ID，按管理员隔离；不保存查询文本、参数、结果或凭证。禁用浏览器存储只影响快捷入口，不影响服务端草稿。

从 **0.4.x 或 0.5.x** 升级，仍需执行[管理员迁移清单](../administrators.zh-CN.md)：以 `admin` 和原密码登录，用个人配置 MCP Token 替换已撤销旧 Token。**0.3.x 或更早**版本按 [PostgreSQL 元数据迁移说明](0.4.0.md#upgrading-from-03x-or-earlier)操作。

## 发行包与证据

下载 `contextgate-0.8.0-linux-arm64.tar.gz` 或 `contextgate-0.8.0-linux-amd64.tar.gz`，使用 `SHA256SUMS` 校验，保留启动器、`libexec` 和私有 C++ 库的完整目录。包含内嵌 UI、中英文帮助、查询/本体/云数仓示例、Apache-2.0 LICENSE/NOTICE 及依赖声明。要求 Linux glibc 2.36+ 与 PostgreSQL 元数据库，运行时无需 Node.js。

[发行附件](https://github.com/SamuelSupe/contextGate/releases/tag/v0.8.0)提供 `release-verification.json`、两份 `dist-*.json` 和两份 `download-*.json`，记录实际提交、CI、包摘要及 GitHub 独立下载回验。包测试覆盖 PostgreSQL/HTTP API、HTTP/stdio、模板与本体上下文、管理员恢复、撤销及两种 OTLP 协议。本地 amd64 通过 OrbStack 仿真执行，CI 使用原生 arm64 和 amd64 runner。

[验收记录](../validation.zh-CN.md)区分各阶段范围。18 产品／20 版本完整矩阵保留为历史证据，本版包测试不冒充完整矩阵重跑。Snowflake、Databricks SQL、BigQuery 和 Redshift 仍为**未在真实厂商环境验证的预览连接器**。不新增跨源联邦查询、本体实例存储、推理、自动查询编译或资源隔离模型。
