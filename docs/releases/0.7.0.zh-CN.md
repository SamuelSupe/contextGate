# ContextGate 0.7.0

**云数仓预览连接器，复用完整语义数据访问流程。**

[English](0.7.0.md) · [云数仓指南](../cloud-warehouses.zh-CN.md) · [配置示例](../../examples/cloud-warehouses/README.md) · [安装](../install.zh-CN.md)

## 新增能力

新增 Snowflake、Databricks SQL、Google BigQuery 和 Amazon Redshift 四种 **Preview 连接器**，复用 `query_sql`、Agent 到数据源授权、语义目录、经过试跑的原生查询模板、本体映射及审计/OTLP。支持中英文管理界面与配置 MCP。

| 连接器 | 认证及查询接口 | 参数 |
| --- | --- | --- |
| Snowflake | SQL API，PAT 或预先签发的 OAuth 访问令牌 | 位置参数 `?` |
| Databricks SQL | Statement Execution API，PAT 或预先签发的 OAuth 访问令牌 | 命名参数 `:name` |
| Google BigQuery | Jobs API，支持 Google 服务账号 JSON 自动刷新令牌，或已有访问令牌 | 命名参数 `@name` |
| Amazon Redshift | PostgreSQL 协议，用户名/密码、TLS、每次查询只读事务 | 位置参数 `$1` |

三个 HTTPS 适配器使用固定 API 路径、证书验证、有界轮询与原生结果分页，并尝试取消远端任务。BigQuery 在执行前通过 dry run 确认 SELECT，并应用可配置的计费扫描字节上限。结构发现、凭证更新及管理员只读声明复用已有配置流程。每个产品均提供数据源 JSON 与可导入的语义模板示例。

## 预览边界

**尚未在真实 Snowflake、Databricks、BigQuery 或 Redshift 环境验证。** 四种连接器包含在发行包中，但不计入已验证的 18 个产品／20 个版本组合。模拟 API 测试证明本地实现行为，不能证明厂商兼容性、账号权限、计费效果或生产可用性。

云 SQL 使用受限的 SELECT 子集，可能拒绝高级方言语法；原生参数仅支持标量，SQL 分页需显式编写。请使用专用读取账号，连通成功和管理员声明均不等于权限验证。认证、结构发现、类型、取消和费用限制详见[指南](../cloud-warehouses.zh-CN.md)。

HTTPS 数据源使用管理员手工维护的连接契约版本。相关云端契约改变后需更新版本，重新试跑并发布模板。不提供跨源查询、统一 SQL 编译或实体结果转换。

## 升级

从 **0.6.x** 升级：备份 PostgreSQL 元数据库、匹配主密钥和部署配置；停止服务，更换为 0.7.0 程序包或镜像，再使用原数据库 URL、密钥和数据目录启动。本版本不新增元数据迁移，也不强制轮换凭证。管理员账号、个人配置 MCP 身份、查询 Agent/OAuth 授权、语义发布和本体映射保留。重启后检查一个已有查询及对应审计。

从 **0.4.x 或 0.5.x** 升级：仍需执行 0.6.0 引入的管理员迁移，以 `admin` 和原密码登录，并将被撤销的旧配置 MCP Token 更换为个人 Token。参阅[账号升级清单](../administrators.zh-CN.md)。0.3.x 或更早版本请按 [PostgreSQL 存储迁移说明](0.4.0.md#upgrading-from-03x-or-earlier)操作。

## 发行包与验证

下载 `contextgate-0.7.0-linux-arm64.tar.gz` 或 `contextgate-0.7.0-linux-amd64.tar.gz`，并使用 `SHA256SUMS` 校验。包含内嵌 UI、私有 C++ 运行库、中英文帮助、云数仓示例、Apache-2.0 LICENSE/NOTICE 及依赖声明。要求 Linux glibc 2.36+ 和 PostgreSQL 元数据库，运行时无需 Node.js。

发行附件记录实际提交、原生 arm64/amd64 CI、两种构建包和 GitHub 独立下载包的验证。包测试覆盖 PostgreSQL 与 HTTP API 查询、HTTP/stdio、语义和本体模板、管理员访问、恢复及两种 OTLP 协议；本地 amd64 包通过 OrbStack 仿真执行。[验收记录](../validation.zh-CN.md)区分开源数据库矩阵、本机 Chrome、模拟云 API 测试及尚缺失的真实云环境验证。
