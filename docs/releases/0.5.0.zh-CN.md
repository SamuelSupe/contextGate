# ContextGate 0.5.0

**HTTP API 数据源、业务查询目录与更简洁的 Agent 使用流程。**

[English](0.5.0.md) · [开始使用](../getting-started.zh-CN.md) · [安装指南](../install.zh-CN.md)

本版本新增固定 GET/POST JSON API 数据源，复用数据源授权、配置 MCP、语义模板、本体映射和审计上报。业务目录默认展示可执行查询；模板支持原生文本、参数位置选择和 API 操作导入；本体映射可按实体聚焦并选择结构字段。

答案验收默认采用单次模式，记录真实客户端调用并保存人工评价和独立历史统计；仍可选择原有流程与语义引导的两次对比。首页引导、发布审阅、健康与审计处理入口、设置分组、中英文和窄屏键盘操作也得到改进。

## 权限边界

API 只读性由管理员声明，ContextGate 强制执行固定请求契约，不能证明任意上游接口没有副作用或账号具备只读权限。连通与权限证据分别展示，API 声明字段仍为未验证。数据库矩阵仍为 18 个产品／20 个版本组合，HTTP API 是额外的数据源类型。详见 [HTTP API 帮助](../http-api.zh-CN.md)。

## 从 0.4.x 升级

1. 备份 PostgreSQL 元数据、匹配的主密钥和部署配置，按[运维指南](../operations.zh-CN.md)回验。
2. 停止旧服务，替换为 0.5.0 发行包或镜像。保留原数据库连接、主密钥目录、数据库文件目录及公开地址，主密钥不能放在临时目录。
3. 启动后检查诊断、所选数据源连接和实际 Agent 查询。已有授权、语义发布及模板证据继续保存于 PG；旧评估保留对比模式，UI 新建评估默认单次验收。
4. 刷新客户端 MCP 工具发现，加载新增 `query_http_api`。

保留 `contextgate` 命令、`mcpdbhub` 别名和 `MCPDBHUB_*` 配置兼容性。从 0.3.x 及更早版本升级仍需遵循[此前的存储切换说明](0.4.0.md#upgrading-from-03x-or-earlier)。

Linux arm64/amd64 包含内嵌 UI、C++ 运行库、中英文文档、示例和依赖声明，要求 glibc ≥ 2.36 和 PostgreSQL 元数据库。下载后校验 `SHA256SUMS`。发行附件记录双架构 CI、数据库矩阵及真实发行包和下载回验；本机 amd64 执行使用 OrbStack 仿真。HTTP 测试仅覆盖隔离示例接口，不代表认证任意第三方 API。
