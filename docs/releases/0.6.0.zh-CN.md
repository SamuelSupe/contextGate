# ContextGate 0.6.0

**多管理员账号、个人配置 MCP 身份，以及 Apache-2.0 开源许可证。**

[English](0.6.0.md) · [管理员指南](../administrators.zh-CN.md) · [安装](../install.zh-CN.md)

## 新增功能

- **独立管理员账号：** 使用用户名和密码登录。超级管理员管理账号、角色与全局设置；所有管理员共享数据源、语义、本体、查询 Agent 和 OAuth 客户端。新账号的临时密码仅展示一次，有效期 24 小时，首次登录必须修改后才能使用业务功能。
- **个人配置 MCP：** 每人拥有一个固定配置身份，同一时间最多一个有效 Token。仅本人可签发、轮换或撤销；超级管理员可以撤销他人的 Token，但不能代领或读取。
- **定向撤销：** 停用、角色变更或超级管理员重置密码会撤销对应账号的会话、配置 Token，并取消在途配置任务。本人正常改密保留当前会话和配置 Token。查询 Agent 及 OAuth 查询授权独立保留。
- **审计归属：** UI 修改、配置 MCP、连接检测、模板试跑及 Agent 预览记录实际管理员与执行身份。支持按管理员、配置身份、入口及结果筛选；账号安全事件仅超级管理员可见。OTLP HTTP/protobuf 与 gRPC 同步这些字段，不记录凭证、参数或结果。
- **Apache-2.0：** ContextGate 正式采用 Apache License 2.0。源码、镜像及 Linux 发行包携带 LICENSE 和 NOTICE；第三方组件保留原许可证及声明。

默认 UI 与文档继续使用英文，可在设置切换简体中文。管理员共享业务资源，本版不引入资源归属、多租户或团队隔离。

## 从 0.5.x 升级

1. 按[备份指南](../operations.zh-CN.md)备份 PostgreSQL 元数据库、匹配的主密钥及部署配置。
2. 停止旧服务，换用 0.6.0 包或镜像，保留数据库 URL、主密钥、数据目录与公开地址。不要让新旧版本同时连接同一元数据库。
3. 启动后，事务迁移创建用户名 **`admin`** 的超级管理员，**保留原密码**。旧浏览器会话失效，需要重新登录。
4. **全部旧配置 MCP Token 失效。** 为实际使用者创建管理员账号，由本人在“设置 → 我的配置 MCP”签发 Token 并更新客户端。
5. 检查账号角色、一次真实查询 Agent 调用，以及配置修改对应的审计记录。

数据源、加密凭证、语义、本体版本、查询 Agent/OAuth 授权、评估及审计历史保留。历史身份不追溯归属到具体人员。迁移可重复执行，失败回滚；回退旧应用需恢复升级前的数据库备份及匹配密钥。

CLI 密码恢复使用 `--username`；仅有一个账号时才可省略。恢复保留目标账号角色及启停状态，不撤销其他管理员权限。详见[恢复说明](../administrators.zh-CN.md)。`mcpdbhub` 命令别名、`MCPDBHUB_*` 配置和既有查询 MCP 契约保持兼容。

## 发行包与验证

提供 `contextgate-0.6.0-linux-arm64.tar.gz`、`contextgate-0.6.0-linux-amd64.tar.gz` 与 `SHA256SUMS`。包内包含内嵌 UI、私有 C++ 运行库、中英文帮助、示例、LICENSE、NOTICE 和依赖声明。要求 Linux glibc 2.36+ 及 PostgreSQL 元数据库，运行时无需 Node.js。

发行附件记录源提交、原生 amd64/arm64 CI、解包及 GitHub 下载回验。打包工作流覆盖 HTTP/stdio、配置 MCP、HTTP API 模板、密码恢复，以及两名管理员经 OTLP 双协议上报审计。本机 amd64 使用 OrbStack 仿真。18 产品／20 版本数据库矩阵及 Chrome 流程保留实际实现摘要和分阶段验证范围，详见[验收记录](../validation.zh-CN.md)。
