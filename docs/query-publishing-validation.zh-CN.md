# 查询发布流程验证

日期：2026-09-16。[English: full stage-by-stage record](query-publishing-validation.md)。本文对应 0.7.0 后开发、在 0.8.0 交付的功能；[最终发行验证](validation.zh-CN.md)单独标识提交和发行包。

## 实际验证

- 功能阶段在 OrbStack 通过 18 产品 / 20 版本数据库矩阵：135 个查询/错误场景、104 个拒绝操作。该阶段后端摘要为 `e64ae2a8ba84bb51a83687a02deb93a803a340ea02f90afe6a3f303323caa662`；后续 UI 优化没有重跑整个矩阵。
- PostgreSQL 与固定 HTTP API 从创建查询、参数编辑、保存恢复、真实试跑、完整草稿审阅到发布均通过。本机 Chrome 创建的两个模板被真实 HTTP MCP 客户端执行；仅模板数据源拒绝原生 SQL。
- 并发编辑保留本地修改及其他草稿条目；凭证变更使模板暂停，仅重新试跑不会恢复，明确重新发布后恢复。三查询支持示例通过八项样例/回归断言，包含空结果与 USD 170.00 金额断言。
- 全部 Go 测试、race 和 vet 在 OrbStack 通过；17 项前端行为测试、2 项无损请求测试及 TypeScript/Vite 生产构建通过。现有 JavaScript 包大小提示仍保留。
- 目录回归覆盖草稿/待处理视图的管理员限制、Agent 投影视图拒绝、摘要不泄露查询正文、停用或过期模板、数据源授权及草稿修订分页。
- Chrome 检查直接打开查询、保留搜索/滚动/焦点、浏览器返回、过期快照显式重启、本体点击与拖动区别、侧栏编辑及键盘操作。检查中英文桌面与 390px 窄屏，无页面横向溢出或应用控制台错误。
- 真实 HTTP MCP 调用使两分钟客户端等待结束，显示匹配数据源、模板、执行版本及 Agent 的请求 ID；预览不计为客户端成功。首页保留多个当前管理员的近期查询引用。
- 重启保留 PostgreSQL 配置、会话和发布；新版英文截图来自本机 Chrome 中的自有测试数据，没有为截图修改业务定义、授权或发布。

## 证据边界

完整数据库矩阵属于功能阶段，不是最终发行提交的新矩阵。最终原生 arm64/amd64 CI、实际 dist 和 GitHub 独立下载的包检查以发行附件为准；本机 amd64 运行使用 OrbStack 仿真。四个云仓库仍未取得真实厂商环境验证。本轮没有新增备份恢复演练。

这些结果不代表客户试点、真实问题的业务正确率或节省工时；请使用[试点记录表](query-pilot.zh-CN.md)收集独立用户配置、问题评审与持续复用证据。目录排序、外部导入、负责人和定时回归仍属于后续决策。
