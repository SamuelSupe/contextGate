# 将已有查询发布为 Agent 工具

[English](query-publishing.md) · [首次使用](getting-started.zh-CN.md)

从 **首页 → 新建查询** 开始，提供已有读取查询或固定 HTTP 读取操作。流程复用现有语义模板、数据源授权和查询引擎，无需先创建本体。

1. **选择数据源。** 选择已有来源或连接新来源。此流程的新来源推荐“仅模板”，保存前明确确认模式；已有来源模式保持原值。连通、引擎保护与账号权限证据分别查看，“未验证”不能当作验证成功。
2. **提供查询。** 粘贴原生查询文本，在“固定参数值与查询选项”中填写参数，或编辑完整 JSON。原生预览支持“将此查询创建为查询工具”。HTTP 数据源可复制已配置操作的参数契约。系统不会自动把 SQL 字面量改成占位符。
3. **用途与参数。** 填写名称、适用问题、参数含义和结果说明。“识别已有参数槽”只为允许的值位置建议名称与 JSON 类型，请人工确认。大整数与 Decimal 保持无损。JSON Pointer 和约束放入高级区；按需补充单位、退款/取消规则、时间边界、空结果含义及回归检查。
4. **验证与发布。** 保存草稿，用真实来源执行示例和检查，查看返回数量与检查结论。打开“审阅并发布”。发布会原子替换此来源整份语义快照；其他目录、模板或本体映射变更也会列出并要求确认。试跑失败、证据过期或修订冲突仍会阻止发布。
5. **确认客户端调用。** 选择已授权 Agent 或新建 Agent，打开客户端接入说明，通过 `search_semantics` → `get_semantic_entry` → `execute_query_template` 调用当前执行版本，使用适用的参数。客户端区域依次完成“接入 Agent、复制工具调用、确认调用”。“等待客户端调用”最多检查 2 分钟，“立即检查”执行一次刷新；离开页面、隐藏标签页、收起面板或查询/授权变化会停止等待，不建立后台监控。证据展示近 30 天内匹配此来源、模板、执行版本与所选 Agent 的非预览成功调用及请求 ID。

在“业务说明”中，可以通过“业务概念”按名称关联已映射概念，并点击查看定义。也可从“本体 → 查询 → 创建查询”开始，自动携带数据源与概念。关联发布后才对 Agent 生效，不改变原生查询。详见[概念与查询操作](ontologies.zh-CN.md#从业务概念使用查询)。

“保存草稿，稍后继续”将内容保存在服务端。“首页 → 继续上次配置”仅记录数据源、模板和 Agent ID；从本体进入时，查询 URL 还可以携带本体与概念 ID。浏览器缓存按管理员区分，不保存查询、参数、结果或凭证；禁用存储时仍可通过已保存查询 URL 恢复。未保存内容有导航保护。保存冲突后，先审阅服务端当前条目，再明确选择将本地条目合并到最新修订；其他条目保留，下一次保存仍检查并发。

查询目录、数据源语义页和本体入口统一使用同一个编辑器。已有查询可直接切换“查询 / 参数 / 业务说明”，每个参数在同一区域编辑契约和示例值；绑定、约束、回归检查按需展开。“保存草稿”不等于发布，新建查询继续使用分步引导。

工作区突出当前下一步：运行检查、审阅变更、接入客户端或预览已发布查询；查询详情通栏展示，“验证与版本”打开侧栏，“Agent 客户端”按需展开接入配置与调用证据。草稿无变更且验证有效时，发布按钮显示为不可操作的“已发布”。发布仍需审阅整个数据源草稿。

首页按管理员保留最多五个最近访问的查询；最近一个作为主要续办入口，其他查询以紧凑列表呈现，再次访问会排到最前。首页根据服务端当前状态显示查询名称与下一步。确认匹配的客户端成功调用后，入口变成“最近使用的查询”；已删除查询提示重新选择，已删除数据源不再显示续办入口。数据源概览默认保持同一个来源。有未完成配置时优先续办，否则突出搜索；待处理项显示具体原因，可直接检查或进入对应修复页面。连接检测、健康检查和查询验证分别标注；没有运行健康检查不等于此前连接检测失败。

查询工作区区分发布状态、当前执行证据和业务验收。用途与契约默认展示已保存草稿；客户端调用使用已发布版本。运行成功不会自动变成业务正确。业务评审仍归属于数据源评估运行，不会自动认定属于此模板；从“业务定义与恢复 → 评审业务问题”进入人工评审。

历史调用也可能来自客户端评估，不能证明当前凭证有效或业务答案正确。首页调用数量覆盖整个来源，包括原生查询；它不能完成某个具体模板的接入。窗口内没有记录表示“未观察到”，不表示永远无人使用。

主导航为首页、查询工具、数据源、本体、Agent、运维和设置。查询工具默认在“可用查询”展示已发布且可执行的查询；管理员可切换到“草稿”查看新增、修改和待删除项，或在“需处理”查看受验证失效、数据源停用影响的已发布启用查询。“全部定义”保留业务目录。切换 Agent 视角后立即回到已发布内容，隐藏管理视图；API 同样拒绝通过 Agent 视角读取草稿。可执行查询按数据源和查询合并，匹配的业务定义作为上下文展示，避免概念与其查询重复占用结果。点击查询名称直接进入工作区，“预览查询”单独试跑已发布版本。打开查询再返回，会恢复搜索词、数据源与 Agent 筛选、分页、滚动位置及选中结果；浏览器后退保留同一快照。发布或授权变化使快照失效时，需要重新检索。管理列表分页同时绑定草稿修订；保存草稿不会使只读已发布目录的分页失效。本体保留一级入口，连接类型说明位于设置次级入口；健康和审计位于运维。所有已有 URL 保持可访问。

可从[客服查询示例](../examples/query-publishing/README.zh-CN.md)开始，使用[试点工作表](query-pilot.zh-CN.md)记录真实配置耗时和业务效果。实现验证不等于已经证明客户收益或答案正确率提升。
