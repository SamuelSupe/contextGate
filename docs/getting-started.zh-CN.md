# 首次使用 ContextGate

[English](getting-started.md) · [帮助文档](README.zh-CN.md)

按[安装指南](install.zh-CN.md)启动服务，访问 `http://127.0.0.1:8080`，使用日志中的一次性设置码创建首个超级管理员的用户名和密码。产品没有默认管理员密码。

从 **首页 → 新建查询** 开始连续五步流程：选择来源、提供已有查询、说明契约、试跑并审阅发布、确认当前版本的真实 Agent 调用。“继续上次配置”会从服务端恢复已保存内容。参阅[发布指南](query-publishing.zh-CN.md)和[无需本体的客服示例](../examples/query-publishing/README.zh-CN.md)。此流程中新建来源推荐“仅模板”，已有模式不变。原生探索和下述高级配置路径仍可使用。

1. **连接数据源。** 数据库使用专用只读账号；JSON REST API 选择 **HTTP API** 并声明固定只读操作及标量参数，详见 [HTTP API 指南](http-api.zh-CN.md)。配置 TLS 和查询限制，测试连接并检查只读证据。“未验证”不能当作只读账号验证成功。网关自身的 PostgreSQL 元数据账号需要读写权限，与目标数据库读取账号分开。
2. **建立语义。** 在数据源的“语义”中导入选定对象的结构骨架，补充字段、术语、单位和指标含义。创建原生查询模板，明确参数绑定及示例参数，并完成真实只读试跑。结构导入不读取业务样本来推断含义。
3. **映射本体（可选）。** 在“本体”中用图形或列表编辑实体、属性及关系，校验后发布。回到数据源的“本体映射”，选择固定发布版本，关联物理对象、字段与模板。检查可发现字段，对无法验证的字段明确声明。映射不自动生成查询，也不保证全部数据满足声明约束。
4. **发布。** 打开“审阅并发布”，查看必需检查、变更条目、显式关联模板，以及可能受影响的已授权 Agent。可直接运行缺失试跑或映射检查，也可进入相应编辑器修复。验证未通过时不能发布。草稿保存不会改变查询 Agent 看到的内容；连接或凭证变更后，相关模板可能需要重新试跑并发布。
5. **授权并接入。** 创建 Agent，选择允许的数据源和有效期，保存仅展示一次的 Token。“连接”提供客户端 HTTP / stdio 配置。查询入口为 `/mcp`；远程客户端使用可达的 HTTPS 地址。先调用 `list_data_sources`，再用 `search_semantics`、`get_semantic_entry` 获取定义及模板契约，最后 `execute_query_template` 执行。使用发现结果中的当前执行版本。
6. **观察。** 查看审计与实际客户端活动；管理员身份预览不等同于外部客户端已连接。查询工作区可“等待客户端调用”，最多等待 2 分钟，只匹配所选 Agent 和当前执行版本，并支持取消。可启用“仅模板”模式限制原生查询，按需配置 OTLP Logs 上报。

想让 Agent 帮忙准备配置时，在 **设置 → 我的配置 MCP** 创建短期专用凭证，连接 `/mcp/config`。该凭证可配置所有数据源和共享草稿，数据源修改立即生效；管理员仍负责发布和查询 Agent 授权。详见[配置 MCP](configuration-mcp.zh-CN.md)。

**查询工具 → 可用查询**显示已发布且可执行的模板，关联概念作为上下文。“草稿”显示新增、修改和待删除查询；“待处理事项”显示因验证失效或来源停用而不可执行的已发布启用查询。这两个管理视图仅管理员可见；选择 Agent 后立即切换到其已发布可见子集。“全部定义”用于查找术语、指标和映射的本体定义。按名称、别名和说明检索并筛选来源，点击查询名称直接进入工作区，“预览查询”执行已发布版本；返回恢复搜索、分页、位置和焦点。概念详情与关联预览保留互相返回的路径。试跑通过不代表所有业务答案正确。

模板编辑器为文本查询家族提供原生查询编辑和完整 JSON 高级模式。“查找参数位置”列出已有且允许绑定的值位置，不创建占位符或插值查询文本；请先在查询选项中添加原生参数槽。HTTP API 模板可从已配置操作复制参数契约与示例。本体映射可按实体聚焦字段和关系，“发现字段”从结构中选择物理字段，不读取业务样本；HTTP API 声明字段仍显示未验证。

在数据源打开“评估业务问题”，默认采用“单次答案”模式：填写业务问题与验收条件，选择 Agent 并开始捕获，让客户端执行任务，收集调用后保存人工结论和备注。需要基线与引导两次运行时才选择“对比”。捕获仅汇总观察到的调用，不自动判断业务正确性，也不保留查询结果。

目录每页 20 条，最多检索前 100 个可访问数据源；更多数据源可通过显式选择单源检索。发布或授权变化后需要重新分页。Agent 视图不包含草稿与未映射本体定义。管理员草稿分页同时绑定草稿修订，保存草稿不影响仅含已发布内容的分页；查询仍在单个已授权数据源中执行。

遇到无数据源、模板不可用或发布失败时，依次检查授权、启停、到期、已发布状态、试跑证据和映射错误。保存冲突应重新读取并合并；旧版本或游标错误应刷新目录并重新分页。通过请求 ID 定位审计，反馈问题时不要提供密码或完整 Token。可从[零售本体示例](../examples/ontologies/retail-demo/README.zh-CN.md)开始体验。
