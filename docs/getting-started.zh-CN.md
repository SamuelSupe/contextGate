# 首次使用 ContextGate

[English](getting-started.md) · [帮助文档](README.zh-CN.md)

按[安装指南](install.zh-CN.md)启动服务，访问 `http://127.0.0.1:8080`，使用日志中的一次性设置码创建管理员密码。产品没有默认管理员密码。

1. **连接数据源。** 添加数据库及其专用只读账号，配置 TLS 和查询限制，测试连接并检查只读证据。“未验证”不能当作只读账号验证成功。网关自身的 PostgreSQL 元数据账号需要读写权限，与目标数据库读取账号分开。
2. **建立语义。** 在数据源的“语义”中导入选定对象的结构骨架，补充字段、术语、单位和指标含义。创建原生查询模板，明确参数绑定及示例参数，并完成真实只读试跑。结构导入不读取业务样本来推断含义。
3. **映射本体（可选）。** 在“本体”中用图形或列表编辑实体、属性及关系，校验后发布。回到数据源的“本体映射”，选择固定发布版本，关联物理对象、字段与模板。检查可发现字段，对无法验证的字段明确声明。映射不自动生成查询，也不保证全部数据满足声明约束。
4. **发布。** 修正校验和试跑错误，检查映射，再发布数据源语义。草稿保存不会改变查询 Agent 看到的内容。连接或凭证变更后，相关模板可能需要重新试跑并发布。
5. **授权并接入。** 创建 Agent，选择允许的数据源和有效期，保存仅展示一次的 Token。“连接”提供客户端 HTTP / stdio 配置。查询入口为 `/mcp`；远程客户端使用可达的 HTTPS 地址。先调用 `list_data_sources`，再用 `search_semantics`、`get_semantic_entry` 获取定义及模板契约，最后 `execute_query_template` 执行。使用发现结果中的当前执行版本。
6. **观察。** 查看审计与实际客户端活动；管理员身份预览不等同于外部客户端已连接。可启用“仅模板”模式限制原生查询，按需配置 OTLP Logs 上报。

想让 Agent 帮忙准备配置时，在 **设置 → 配置 MCP** 创建短期专用凭证，连接 `/mcp/config`。该凭证可配置所有数据源和共享草稿，数据源修改立即生效；管理员仍负责发布和查询 Agent 授权。详见[配置 MCP](configuration-mcp.zh-CN.md)。

遇到无数据源、模板不可用或发布失败时，依次检查授权、启停、到期、已发布状态、试跑证据和映射错误。保存冲突应重新读取并合并；旧版本或游标错误应刷新目录并重新分页。通过请求 ID 定位审计，反馈问题时不要提供密码或完整 Token。可从[零售本体示例](../examples/ontologies/retail-demo/README.zh-CN.md)开始体验。
