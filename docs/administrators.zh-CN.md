# 管理员账号与个人配置 MCP

[English](administrators.md) · [文档入口](README.zh-CN.md)

ContextGate 支持单实例中的多个实名管理员账号。所有管理员共享数据源、语义目录、本体、查询 Agent 和 OAuth 查询客户端；两级角色控制账号和系统管理能力，不进行业务资源隔离。

## 登录和添加管理员

初始化时使用一次性设置码，选择用户名和密码，创建首个**超级管理员**。用户名不区分大小写，支持 3–64 位 ASCII 字母、数字、点、下划线及连字符，创建后不可修改。显示名称支持中文等语言。

1. 超级管理员打开**设置 → 管理员账号**，选择**添加管理员**。
2. 输入用户名、显示名称及角色。
3. 保存仅展示一次的临时密码，直接交给对应管理员。有效期为 24 小时。
4. 新管理员登录后必须换成不同的个人密码，才能访问业务功能。在此之前只能改密或退出。临时密码过期后由超级管理员重新重置。

账号可停用和重新启用，不提供删除。不能停用自己或修改自己的角色；并发操作也不能移除最后一个启用的超级管理员。旧修订保存返回 409，需要刷新后再编辑。

## 权限

| 功能 | 管理员 | 超级管理员 |
| --- | --- | --- |
| 数据源、语义、本体及发布 | 支持 | 支持 |
| 查询 Agent 授权、OAuth 客户端及同意 | 支持 | 支持 |
| 业务配置与查询审计 | 支持 | 支持 |
| 个人密码、语言及自己的配置 MCP Token | 支持 | 支持 |
| 管理员账号、角色、停用与重置密码 | 不支持 | 支持 |
| OTLP、诊断和健康检查策略 | 不支持 | 支持 |
| 账号安全审计、撤销他人的配置 Token | 不支持 | 支持 |

后端 API 同样强制校验。超级管理员也不能代领他人的配置 Token，不能查看密码或已签发 Token。

## 我的配置 MCP

每个账号对应一个固定配置身份，创建账号时不会自动签发 Token。打开**设置 → 我的配置 MCP**，选择**签发我的 Token**，设置期限并复制 HTTP 或 stdio 配置。默认 24 小时，最长 30 天。Token 仅展示一次，请及时保存。

**轮换我的 Token** 保持身份 ID，立即使旧 Token 失效并取消该身份正在执行的配置任务，需要同步更新所有客户端。**撤销**不会删除身份，之后可重新签发。配置 MCP 操作均关联到所属管理员。

配置 MCP 可以修改全部源的连接、准备语义和本体草稿、发现结构及试跑模板；发布、查询授权、账号和全局设置仍通过管理 UI 完成。查询 Agent 与 OAuth 查询凭证独立。参阅[接入说明及工具清单](configuration-mcp.zh-CN.md)。

## 凭证生命周期

- 本人正常改密：保留当前会话，撤销本人的其他会话，配置 Token 保持有效。
- 调整角色、停用账号或超级管理员重置密码：撤销该账号全部会话及配置 Token，取消该人的配置任务和 UI 预览。
- 超级管理员重置密码：生成新的临时密码，首次登录必须更换。
- 配置 Token 轮换或撤销：立即失效并取消相关任务，不退出浏览器会话。
- 重新启用账号：不会恢复旧会话或旧 Token。
- 以上操作均不改变其他管理员、查询 Agent 或 OAuth 查询授权。已提交的配置变更保留。

请求入口、配置提交和返回查询结果前复查身份；相关游标绑定管理员、会话或配置凭证版本。

## 审计

在**审计日志 → 全部活动**或**管理变更**查看业务操作，按管理员、配置身份 ID、调用入口和结果筛选。使用查询 Agent 身份预览时，同时记录实际管理员和执行所用 Agent。

只有超级管理员可查看**账号安全**事件，包括账号创建、角色/状态变更、改密、Token 操作和认证事件。普通管理员不能通过其他筛选条件或直接 API 读取这些记录。CLI 恢复以 `local_operator` 和 `cli` 入口记录，目标账号作为资源；服务器访问权限不等于某个 UI 账号身份。

审计保存身份、已验证的用户名、操作、提交字段类别、修订、请求 ID、耗时和结果，不保存密码、Token、完整定义、查询参数及结果。先记录意图、后记录结果；意图不可写时拒绝变更，结果记录失败保留可识别的待确认事件。新增字段同步到 [OTLP Logs](audit-export.zh-CN.md)。

## 从 0.5.0 或更早的 PostgreSQL 版本升级

本功能从 0.6.0 开始提供。升级前备份 PostgreSQL 元数据库及对应主密钥。

首次启动在同一事务中迁移旧密码哈希到用户名 **`admin`** 的超级管理员，原密码不变；旧浏览器会话失效，需要重新登录。**所有旧配置 MCP Token 均被撤销**，每名管理员需进入个人配置 MCP 重新签发并更新客户端。

数据源、数据库凭证、语义、本体、查询 Agent/OAuth 授权、评估及审计保留。旧 `admin` 和配置身份审计保留为历史身份，不猜测具体操作者。迁移可重复执行，失败回滚。不要让新旧服务同时连接同一元数据库；回退应用时还需恢复升级前的数据库及对应密钥。0.3.x 及更早的 SQLite 元数据仍适用[单独的 PG 升级流程](releases/0.4.0.md#upgrading-from-03x-or-earlier)。

## 忘记密码后的本地恢复

停止服务，使用同一 `MCPDBHUB_DATABASE_URL`、密钥目录及主密钥，通过 stdin 提交新密码：

```sh
read -r -s contextgate_new_password
printf '%s' "$contextgate_new_password" | contextgate reset-password \
  --data-dir /原配置目录 --username alice --password-stdin
unset contextgate_new_password
```

之后重启服务。只有恰好一个管理员账号时才能省略 `--username`。恢复保持目标账号角色及启停状态，只撤销该账号的会话和配置 Token，记录安全事件，不影响其他管理员及查询授权，也不会自动启用停用账号。

完整管理 API 及请求契约见[英文接口表](administrators.md#management-api)。管理接口使用 Cookie，写请求还需 `/api/session` 提供的 CSRF Token；修订号采用 JSON 字符串。
