# 内部客服查询示例

[English](README.md) · [查询发布指南](../../docs/query-publishing.zh-CN.md)

此 PostgreSQL 示例包含三个虚构业务查询、业务说明和回归条件，无需本体。在**独立的可丢弃样本数据库**中执行 `psql "$DEMO_DATABASE_URL" -f setup.sql`。脚本新建专用 schema，已有同名 schema 时失败，不覆盖原数据。创建只拥有 `support_demo` 的 `USAGE` 和表 `SELECT` 权限的独立登录，排除继承的写权限，参照[只读账号指南](../../docs/read-only-accounts.zh-CN.md)。ContextGate 数据源设为“仅模板”。

打开“发布一个查询”，选择来源，将 `postgres-semantics.json` 中某个模板的 `query_json` 粘贴到“高级 JSON”，识别参数槽并按示例命名，补充用途和结果说明，保存、试跑并审阅发布。也可在来源语义页面导入整个文件得到草稿，再从引导中继续。导入不会带入试跑证据或自动发布。

| 客户端问题与输入 | 预期可观察行为 |
| --- | --- |
| 查询客户 1 的订单，`customer_id=1` | 两行，订单 101 和 102，包含已取消订单。客户 999 返回空结果。 |
| 订单 101 退款了吗，`order_id=101` | 一笔已完成的 USD 10.00 退款；订单 102 没有退款记录，不能解释成已完成的零金额退款。 |
| UTC 9 月 1 日（含）至 9 月 4 日（不含）的已支付订单总额 | 两笔已支付订单，USD 170.00；排除取消订单，**不扣除** USD 10.00 退款，不是净收入。 |

授权查询 Agent，使用 `search_semantics`、`get_semantic_entry` 获取契约，再用当前执行版本调用 `execute_query_template`；在工作区确认对应请求 ID。第二个 Agent 可在数据源授权后复用相同模板。演示数据不能用于宣称真实团队复用、正确率或维护收益。

HTTP 分支复用 [HTTP API 示例](../../docs/http-api.zh-CN.md)：启动样本服务并配置来源，在“发布一个查询”选择已配置操作。参数契约和示例会被复制，不会改写固定 HTTP 操作或替换 URL。

客户和订单 ID 只是查询输入，**不是行级授权规则**。面向终端客户的权限需要数据库账号/视图，或另行设计可信的用户身份边界。每个查询仅访问一个来源，多次调用没有统一快照保证。
